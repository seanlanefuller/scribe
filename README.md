# Scribe

Scribe is a lightweight web tool for converting ABC notation into a treble staff and MIDI. It allows users to write music in ABC notation, visualize it on a sheet music staff, and export it as a MIDI file.

## Features

- **ABC Notation Support**: Parse and render standard ABC notation.
- **Dynamic Rendering**: Visualize music on a treble staff in real-time.
- **MIDI Export**: Export your compositions as `.mid` files.
- **Pagination**: Navigate through long scores with ease.
- **Customizable Tempo**: Adjust BPM for MIDI export.

## Getting Started

Simply open `scribe.html` in any modern web browser. No installation or build steps are required.

## Usage

1. Enter your ABC notation in the textarea.
2. Adjust the BPM if necessary.
3. Click "Draw" to render the staff.
4. Click "Export MIDI" to download the MIDI file.
5. Use "Previous" and "Next" buttons to navigate through pages.
